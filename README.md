## >프로젝트 소개

- **서비스명**: 카페인리듬 (Caffeine Rhythm)
- **소개**: 개인 생체 데이터와 일상 스케줄을 바탕으로 최적의 카페인 섭취 골든타임을 역산하여 제시하는 웹 기반 라이프스타일 헬스케어 서비스
- **개발 기간**: 2026.07.01 - 2026.08.30
- **개발 인원**: 1인

## **>주요 기능**

- 기본 정보(나이, 체중, 카페인 민감도) 기반 맞춤형 카페인 섭취 및 수면 가이드 제공
- 내 몸에 남아있는 카페인 잔여량을 그래픽(게이지)으로 시각화
- 사용자 생체·섭취 데이터가 자동 바인딩된 개인화 1:1 건강 코칭 LLM 챗봇
